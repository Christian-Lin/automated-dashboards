# Automated Dashboards

Self-contained HTML dashboards. Each folder holds one dashboard as a single `index.html` (libraries from a CDN, data embedded), so it can be opened directly or served with GitHub Pages.

| Dashboard | What it shows |
|---|---|
| [Alexa Review Insights](alexa-review-insights/) | Negative-review rates, rating mix and review text for 2,435 Amazon Echo and Fire TV Stick reviews (May–Jul 2025) |
